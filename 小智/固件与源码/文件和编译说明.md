## 跑通后想自己编译

1. 解压源码到英文路径，进入有 `CMakeLists.txt` 和 `scripts` 目录的 `xiaozhi-esp32-2.5.2` 文件夹。
2. 自行编译时用官方推荐的 **ESP-IDF `release/v6.1` 分支**，安装工具和子模块后，打开 ESP-IDF 终端。上游记录了 `v6.1` 标签编译的 ESP32-C3 固件可能无法启动 Wi-Fi。只烧录本页的官方 BIN 时直接用烧录工具。 [乐鑫 Windows 环境安装文档](https://docs.espressif.com/projects/esp-idf/en/stable/esp32/get-started/windows-setup.html) · [上游 SDK 说明](https://github.com/78/xiaozhi-esp32/issues/2344)
3. 在源码根目录运行官方构建脚本。首次需要联网下载构建依赖。发布构建使用 Linux 环境。如果 Windows 工具链出现兼容问题，可参照官方发布流程在 Linux 环境重试。 [v2.5.2 官方发布工作流](https://github.com/78/xiaozhi-esp32/blob/v2.5.2/.github/workflows/release.yml)

   ```powershell
   python scripts/build.py xmini/c3 --name xmini-c3 --zip
   ```

4. 成功后在 `releases` 目录找到 `v2.5.2_xmini-c3.zip`，解压里面的 `merged-binary.bin`，再按主教程烧录。板子的按键、显示屏和音频配置在 `main/boards/xmini/c3/`。本地运行官方脚本核对了这个板型和编译目标，随包 `.bin` 使用上游发布的构建结果。
