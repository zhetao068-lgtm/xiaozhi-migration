# 小智 C6 双击烧录

适用于 **64 位 Windows 10/11** 和 **微雪 ESP32-C6-LCD-0.85（8 MB）**。先用能传数据的 USB-C 线。文件夹里的工具和固件已备齐。

## 只需这三步

1. **让小智进入下载模式。** 先拔 USB，电池供电时长按中间 **PWR** 关机。按住 **BOOT/-** 再插 USB 到电脑，等电脑识别后松手。桌上只接这一台 ESP32。 [微雪官方操作](https://docs.waveshare.net/ESP32-C6-LCD-0.85/Instructions-For-Use/)
2. **在 Windows 资源管理器双击 [双击烧录.cmd](双击烧录.cmd)。** 核对外壳或订单正好是 **ESP32-C6-LCD-0.85**，输入 **Y** 后回车。脚本自动找串口、检查芯片和 Flash、备份、烧录和读回。保持数据线连接，等窗口显示 **「烧录和读回校验通过」**。芯片只能识别为 ESP32-C6，外壳型号由你确认。
3. **看到通过后拔 USB，正常开机。** 带电池时长按 PWR 关机、再短按开机。连小智发出的 `Xiaozhi-…` 热点，填 **2.4 GHz** Wi-Fi 密码并绑定小智账号。按 [开机和配网说明](../../03-C6使用说明.md#2-第一次配网和绑定) 做一次。

如果已经是官方小智固件，开机、配网和对话都正常，可以直接使用。卖家原厂演示、带厂商品牌画面或需要重刷时，才用上面的烧录流程。

| 窗口提示 | 这样处理 |
|---|---|
| 没检测到设备 | 换能传文件的线，先让设备关机，再按住 BOOT/- 插线。 |
| 多个设备 | 拔掉别的 ESP32，保留这一台再双击。 |
| 型号、保护状态或 Flash 容量检查失败 | 记录提示，按卖家对应型号的说明处理。 |
| 写入或读回失败 | 保留窗口上的提示和原机备份。备份在 `%LOCALAPPDATA%\Xiaozhi-C6\Backups`。同一块板的恢复步骤见 [固件说明](../说明.md#只有接上-c6-实物后才运行)。 |

烧录会覆盖旧 Wi-Fi 设置。原机备份每次单独保存，备份和校验文件留在自己电脑上。
