### 可复现的离线校验

新手直接用 [图形工具教程](../00-随身版制作指南.md#2-收到-c6-版先开机必要时烧录)。以下命令方便老师或家长复核，不需要插板。先把 **C6 ZIP** 解压到英文目录，打开该目录下的 PowerShell。装过 Python 的 Windows 可以这样做。第一组命令只读取固件；临时环境装在当前目录的 `.venv`。

```powershell
python -m venv .venv
$py = '.\.venv\Scripts\python.exe'
& $py -m pip install --index-url https://pypi.org/simple 'esptool==5.6.0'
& $py -m esptool version
Get-FileHash -Algorithm SHA256 .\merged-binary.bin
& $py -m esptool --chip esp32c6 image-info .\merged-binary.bin
```

这份 C6 `merged-binary.bin` 的 SHA-256 是 `b71061de4e8de75427f1aea32eba5900d1e6c1ae356ca631b294a47d18950c9d`。`image-info` 从合并文件首部读到的是启动镜像。要复现应用校验，可以把 `0x20000` 至 `0x310000` 之前这段提取到一个单独的临时文件。这个临时文件只用于检查，不拿去烧录。

```powershell
& $py -c "from pathlib import Path; data=Path('merged-binary.bin').read_bytes(); Path('c6-app-check.bin').write_bytes(data[0x20000:0x310000])"
& $py -m esptool --chip esp32c6 image-info .\c6-app-check.bin
```

### 只有接上 C6 实物后才运行

已经能聊的小智可以直接使用。只有需要换固件时才备份和烧录。电脑若没识别端口，先拔线，按住 BOOT/- 再插入 USB，识别后松手。把下面的 **`COM7` 换成你这块板新出现的端口**。每次如果重新枚举，以设备管理器的新端口为准。图形工具也能在 `Read Flash` 页填起始 `0x0`、大小 `0x800000` 读取整片。 [微雪下载模式说明](https://docs.waveshare.net/ESP32-C6-LCD-0.85/Instructions-For-Use/) · [乐鑫 Read Flash 说明](https://docs.espressif.com/projects/esp-test-tools/zh_CN/latest/esp32c6/production_stage/tools/flash_download_tool.html)

**先做只读检查和备份。** `flash-id` 应识别 8 MB Flash。`get-security-info` 如显示安全启动或 Flash 加密已启用，或保护状态无法确认，停下来用卖家的恢复说明。原程序可以使用时，要有成功备份或准确的出厂恢复包，再继续写入。各条命令间如果板子退出下载模式，就重新按 BOOT/- 插线。

```powershell
$port = 'COM7'
& $py -m esptool --chip esp32c6 --port $port flash-id
& $py -m esptool --chip esp32c6 --port $port get-security-info
& $py -m esptool --chip esp32c6 --port $port read-flash 0x0 0x800000 C6-original.bin
(Get-Item -LiteralPath .\C6-original.bin).Length
Get-FileHash -Algorithm SHA256 .\C6-original.bin
```

备份文件长度必须是 **8,388,608**，保存哈希。里面可能有 Wi-Fi 和设备信息，留在自己电脑。**确认型号和备份后再写入。** `write-flash` 会校验写入的数据，观察 `Hash of data verified`。额外用 `verify-flash` 时应在首次正常启动之前验证，避免固件启动后修改了设置分区而造成预期差异。下面两条都保留在下载模式。完成后松开 BOOT/-，手动重启。 [乐鑫读、写与校验命令](https://docs.espressif.com/projects/esptool/en/latest/esp32c6/esptool/basic-commands.html)

```powershell
& $py -m esptool --chip esp32c6 --port $port --after no-reset write-flash 0x0 .\merged-binary.bin
& $py -m esptool --chip esp32c6 --port $port --after no-reset verify-flash 0x0 .\merged-binary.bin
```

**只在需要回退时做。** 确认这是**同一块板、未加密的完整备份**，文件大小和 SHA-256 都与备份时一致。重新进入下载模式，再把原备份写回 `0x0`。卖家提供的分段恢复文件要按卖家地址，不能套用整片命令。

```powershell
& $py -m esptool --chip esp32c6 --port $port --after no-reset write-flash 0x0 .\C6-original.bin
& $py -m esptool --chip esp32c6 --port $port --after no-reset verify-flash 0x0 .\C6-original.bin
```

## 可选编译｜用按键版做续航对照

先用官方 BIN。旧版说明曾建议改 300 秒关机参数。复核确认这块 C6 板的 `BATTERY_EN_PIN` 为 `GPIO_NUM_NC`，所以回调没有可控制的断电引脚，不需要为此改定时器。 [板型引脚配置](https://github.com/78/xiaozhi-esp32/blob/v2.5.2/main/boards/waveshare/esp32-c6-lcd-0.85/config.h) · [电源实现](https://github.com/78/xiaozhi-esp32/blob/v2.5.2/main/boards/waveshare/esp32-c6-lcd-0.85/power_manager.h)

如果原版实测不够 5 小时，而且平时愿意双击 BOOT/- 发起对话，可以试按键版。先读出并保存工作正常的原机固件，保留随包官方 ZIP。将源码解压到一个单独的英文目录，打开 ESP-IDF **6.1.0** 终端，在有 `scripts` 的源码根目录运行以下命令。该选项关闭唤醒词识别，仍使用同一板型和 8 MB 分区配置。 [官方构建脚本](https://github.com/78/xiaozhi-esp32/blob/v2.5.2/scripts/build.py) · [乐鑫 Windows 安装说明](https://docs.espressif.com/projects/esp-idf/en/stable/esp32/get-started/windows-setup.html)

```powershell
python scripts/build.py waveshare/esp32-c6-lcd-0.85 --name esp32-c6-lcd-0.85 --wake-word disabled --zip
```

成功后把构建目录 `releases` 中的 ZIP 另存为 `C6-按键版-实验.zip`，避免同名覆盖已校验的官方 ZIP。解压其中的 `merged-binary.bin`，按 C6 的 `0x0` 烧录步骤刷入。先测双击 BOOT/- 能否对话、空闲能否显示时间，再在相同网络、音量和亮度下与原版比较。若不稳定，用原备份或官方 ZIP 恢复，必要时重新配网。

已调用官方构建脚本的板型配置流程，确认传给 ESP-IDF 的配置选择 `CONFIG_WAKE_WORD_DISABLED=y`、关闭 `CONFIG_USE_ESP_WAKE_WORD`，并保留 C6 目标和原分区。本轮实际运行 `idf.py --version` 返回 `CommandNotFoundException`，也未找到 `IDF_PATH`、常用 ESP-IDF 安装目录或 `riscv32-esp-elf-gcc`。WSL 未安装发行版。因此没有可用的 ESP-IDF 6.1 工具链来执行编译，本轮没有实验 BIN。esptool 可以验镜像和烧录，它不提供编译工具链。
