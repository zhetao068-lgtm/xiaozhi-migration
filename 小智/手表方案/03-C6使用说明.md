# 小智 C6 随身版使用说明

适用型号 **微雪 ESP32-C6-LCD-0.85 带电池版**。随包固件为小智官方 **v2.5.2**。收到时已经是小智界面，直接从第 2 节开始。若已经用自己的网络和账号聊过，直接看第 4 节。第一次使用需要配网并绑定自己的小智账号。用现有热点和免费账号功能，新增功能费用 **0 元**。

## 1. 先用原壳开机

1. 核对订单和板子是 **ESP32-C6-LCD-0.85**。如果卖家已经装好电池，直接试开机。电池分装时先关机、拔 USB，按微雪组装图安装原配带插头的 **3.7 V 电池**，保留电池和主板之间的绝缘片。插头型号或正负极有疑问，请让卖家装好。 [微雪组装图](https://docs.waveshare.net/ESP32-C6-LCD-0.85/Instructions-For-Use/#产品组装说明)
2. 电池供电时，短按中间 **PWR** 开机，长按 PWR 关机。电量不足先用 USB-C 接 5 V USB 电源。先用原壳测完屏幕、录音和喇叭，再装自己打印的托架。
3. 看开机画面。显示小智或播报配网提示，继续第 2 节。若显示红绿蓝、硬件信息等微雪演示页，按第 3 节刷小智。**还没购买时**，可以让卖家发货前用电池开机，确认小智画面和语音正常，并保留给你绑定的状态。 [微雪出厂演示及电源按键](https://docs.waveshare.net/ESP32-C6-LCD-0.85/ESP-IDF/)

## 2. 第一次配网和绑定

1. 准备能上网的 **2.4 GHz Wi-Fi**。用手机热点时，手机 A 开热点，手机 B 或电脑给小智填密码。iPhone 如有「最大兼容性」，把它打开。第一次也可以直接用家里 2.4 GHz 路由器。
2. 用手机 B 或电脑连接小智发出的 **`Xiaozhi-…`** 热点。提示「没有互联网」时选择继续连接。配网页未自动弹出，就在浏览器输入 **`http://192.168.4.1`**，或使用屏幕显示的地址。
3. 在配网页选手机 A 或家里 Wi-Fi 的名字，输入它的密码，点连接。等小智连网。屏幕或喇叭给出 **六位设备码**后，让手机或电脑回到能上网的网络。
4. 用自己的账号打开 [小智官方控制台](https://xiaozhi.me/console/agents)。进入智能体，选「添加设备」，按提示输入六位码。需要选设备类型时用「开源版」，使用已有的免费模型。若平台提示设备已被别人绑定，让原绑定方或卖家先解除。 [小智官方配网与登记说明](https://xiaozhi.me/home/zh/getting-started/)
5. 小智进入待机后，**快速双击 `BOOT/-`**，等进入聆听，说「你好，请用一句话介绍自己」。听到回答后再试直接说「你好小智」。返回待机时观察屏幕是否显示与手机相近的时间。

## 3. 收到的是演示程序时怎么烧录

**初次刷机请先用 [一键烧录说明](固件/C6-直接烧录/一键烧录说明.md)**。按住 BOOT/- 插数据线，在资源管理器双击 [双击烧录.cmd](固件/C6-直接烧录/双击烧录.cmd)，看清外壳型号后按 **Y** 和回车。电脑会自己备份、烧录和读回校验。窗口显示通过后，再按第 2 节配网。

### 备用图形工具操作

本节只给 **ESP32-C6-LCD-0.85** 使用。电脑端只需要数据线、乐鑫图形工具和已解压的 BIN。源码 ZIP 用来查看或自行编译。

1. 将本地 [乐鑫图形工具 ZIP](固件/C6-直接烧录/Espressif-Flash-Download-Tool.zip) 和 [C6 专用 BIN](固件/C6-直接烧录/XIAOZHI_C6_085_v252.bin) 放到英文目录，例如 `C:\XiaozhiC6`。解压工具 ZIP，运行其中的 `flash_download_tool_3.9.11.exe`。 [乐鑫原始下载](https://dl.espressif.com/public/flash_download_tool.zip)
2. 拔 USB。若机器靠电池仍在运行，先用 **PWR** 关机。按住 **BOOT/-**，把 USB-C 数据线插入电脑，出现新端口后松手。在 Windows「设备管理器 → 端口（COM 和 LPT）」看插拔时新增的 **COM 号**。 [微雪下载模式说明](https://docs.waveshare.net/ESP32-C6-LCD-0.85/Instructions-For-Use/)
3. **先备份。** 选择对应的 C6 端口，按 [原机备份说明](固件/说明.md#只有接上-c6-实物后才运行) 读出整片 Flash，或先取得卖家确认适用同一块板的恢复包。整片备份应为 **8,388,608 字节**。如果卖家设备启用了安全启动或 Flash 加密，用卖家提供的恢复流程。
4. 图形工具选择下表参数。只勾选 C6 BIN 那一行，点 **START**，等 **FINISH**。 **ERASE** 会擦整片 Flash，普通烧录直接点 START。该整包本身会清除旧 Wi-Fi 设置，完成后走第 2 节。

   | 项目 | 选择 |
   |---|---|
   | 芯片 / 工作模式 / 下载方式 | `ESP32-C6` / `Develop` / `USB` |
   | 文件 | `XIAOZHI_C6_085_v252.bin` |
   | 地址 | **`0x0`** |
   | SPI 设置 | 勾选 `DoNotChgBin`，沿用镜像设置 |
   | COM / BAUD | 插板新出现的 COM，先试 `115200` |

5. 烧录完成后放开 BOOT/-，重新上电。带电池时可拔 USB，用 **PWR** 完整关机再短按开机。应出现小智界面和配网提示。若原厂演示能显示、刷完小智只有背光或黑屏，先按备份恢复说明处理。 [乐鑫图形工具说明](https://docs.espressif.com/projects/esp-test-tools/zh_CN/latest/esp32c6/production_stage/tools/flash_download_tool.html) · [固件检查和恢复](固件/说明.md#c6-源码和首启复查)

## 4. 日常使用和到手验收

| 想做什么 | 操作或通过标准 |
|---|---|
| 唤醒并说话 | 说「你好小智」，或双击 `BOOT/-`。出现聆听状态再开口。 |
| 调音量 | 单击 `+` 增大，单击 `BOOT/-` 减小。长按 `BOOT/-` 会静音，单击 `+` 恢复声音。 |
| 看时间 | 连网后让它回到待机，和手机时间对一下。 |
| 试免费歌曲 | 说「请播放一首你能播放的免费儿歌」。听到歌声和曲调算通过，曲目以账号可用范围为准。 |
| 试记忆 | 控制台有免费长期记忆时，请它记一个虚构代号。重启、连网、发起新对话后再问。 |
| 换 Wi-Fi | 小智还在线时说「重新配网」并确认。旧热点无法连接时，可重启并等约一分钟，观察是否出现 `Xiaozhi-…` 配网热点。 |
| 验电池 | 拔 USB 后看屏幕和对话是否正常。关机再开、联网、再次对话，才算首次使用验收通过。5–10 小时单独实测。 |

[免费功能与验收](官方功能包/README.md) · [续航和热点重连测试](02-二轮优化与验收.md) · [v2.5.2 板级按键源码](https://github.com/78/xiaozhi-esp32/blob/v2.5.2/main/boards/waveshare/esp32-c6-lcd-0.85/esp32-c6-lcd-0.85.cc)

| 遇到的问题 | 先检查 |
|---|---|
| 插 USB 没有新 COM | 换能传数据的线和电脑 USB 口。让设备完全关机，再按住 BOOT/- 插线。 |
| 连着小智热点但打不开配网页 | 继续连接无互联网的热点，手动输入屏幕上显示的 `http://` 地址。 |
| 配网失败或没有六位码 | 检查是不是 2.4 GHz、密码对不对、热点本身能否上网。已绑定自己账号的设备可直接试聊天。 |
| 双击后只有界面变化，没有声音 | 单击 `+` 两三次检查是否被静音。确认仍有网络，再说一句短问题。 |
| 已经联网，屏幕不显示或花屏 | 先关机重开，核对型号和使用的 BIN。原厂画面正常而小智异常时，回退到同一台设备的备份并请卖家核对板型。 |
