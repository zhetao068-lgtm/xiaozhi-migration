# C6 腕带保护壳

打印 [C6腕带保护壳.stl](C6腕带保护壳.stl)。适配微雪 **ESP32-C6-LCD-0.85** 方盒整机，按原壳 **46 × 46 × 22.5 mm、四角 R5.80 mm** 制作。整机连着原壳从上方卡入，电池和音频部件在原来的位置。打印件约 **64 × 51.1 × 27.6 mm**。腕带槽长 **22.6 mm**、开口宽 **3.5 mm**，可穿约 **20–22 mm** 宽的薄软带。 [微雪原壳尺寸图](https://docs.waveshare.net/assets/images/ESP32-C6-LCD-0.85-details-size-8259db23c36824cbee71518f0c349a63.webp)

1. 用切片软件打开 STL，单位选 **毫米**，比例 **100%**。让大平底贴打印板，四个卡扣朝上。模型已按这个方向摆好。
2. 建议用 **PETG**，**0.4 mm** 喷嘴、**0.20 mm** 层高、**4 道壁、20% 填充**，支撑关闭。用你打印机和耗材对应的温度配置。卡扣需要一点弹性。
3. 把小智屏幕朝上，先将一边的两个角压入卡扣下，再轻轻拨开另一边卡扣并压下。卡扣只压原壳外边。确认 USB-C 插头能直插，三个按键能按到，声音正常。
4. 将软腕带穿过两侧槽，并折回固定。第一次在桌面上轻晃几下，四角都扣牢再佩戴。打印机尺寸误差或原壳批次可能影响松紧，卡得太紧时别硬压。

模型按标称外壳尺寸留了 **每侧 0.45 mm** 的横向余量，安装方向可把 USB-C 朝下、按键朝上。实物还没试装。需要微调时，可编辑 [模型源码](C6腕带保护壳.py) 的 `SIDE_CLEARANCE`，用 Python 安装 `numpy`、`manifold3d`、`trimesh` 后重新导出。改尺寸时保留原始 STL，方便比较。
