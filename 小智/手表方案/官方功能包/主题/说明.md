# 给 C6 彩屏换配色

只用于 **微雪 ESP32-C6-LCD-0.85、8 MB Flash、小智官方 v2.5.2、资源分区地址 0x600000**。先把原机装好、配网并测过基本聊天。其他板型、其他版本和卖家深度定制版先核对实际分区。

| 文件 | 用途 | SHA-256 |
|---|---|---|
| [study-assets.bin](study-assets.bin) | 浅色改为浅青，深色改为深蓝 | `c0145a4d528562b0e67cdf7af2ed978c547828d4ca871668cda1dbfeafbd2439` |
| [stock-assets.bin](stock-assets.bin) | 官方 v2.5.2 原厂资源 | `27107d308be19d3b226f3633a5afd8af48a1d83309f9e11d69a89b8537bd9be0` |
| [制作主题.py](制作主题.py) | 从随包官方 ZIP 重建上面两份文件，保留原字库、唤醒模型和表情 | 用 Python 3 运行，无需安装第三方库 |

1. 按 [完整备份说明](../../固件/说明.md#只有接上-c6-实物后才运行) 先读出本机 Flash。若你原本已有第三方主题，回退时优先用自己的备份。
2. 在乐鑫 Flash Download Tool 选 `ESP32-C6` 和 USB 下载端口，按固件说明进入下载模式。把 `study-assets.bin` 复制到英文路径，只勾选这一行，把地址填 **`0x600000`**。选正确的 COM 口，有 `DoNotChgBin` 时勾选。资源 BIN 使用它自己的分区地址。**整包固件的 `0x0` 地址和 ERASE 按钮在这一步都不要用。**
3. 点 START，看到 FINISH 后重启。语音试「切换到浅色主题」和「切换到深色主题」，再检查状态、时间、对话和默认唤醒。想恢复官方配色，用 `stock-assets.bin` 重复这一步，地址仍为 **`0x600000`**。如果设备当前固件与该分区布局不同，按原机备份恢复说明处理。
4. 想换颜色，在源码里修改 `skin` 的四个六位 RGB 色值，在此文件夹运行 `python .\制作主题.py`，再刷生成的 `study-assets.bin`。配色以外的字体、图片、表情和兼容的预设唤醒模型可从官方生成器着手。选 C6、LCD、128 × 128，注意资源总大小 2 MiB，并保留可回退的原厂资源。

电脑验证了官方整包哈希、分区起始地址和大小、资源记录、校验和，以及字体、模型和表情逐字节一致。实物烧录和主题显示还需要上机验证。 [官方资源格式](https://github.com/78/xiaozhi-esp32/blob/v2.5.2/main/assets.cc) · [官方 8 MB 分区表](https://github.com/78/xiaozhi-esp32/blob/v2.5.2/partitions/v2/8m.csv) · [官方主题生成器](https://github.com/78/xiaozhi-assets-generator)
