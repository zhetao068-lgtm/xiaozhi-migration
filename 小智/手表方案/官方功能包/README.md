按 **微雪 ESP32-C6-LCD-0.85 带电池版 + 小智官方 v2.5.2** 制作。原壳约 **46 × 46 × 22.5 mm**。**功能费用按 0 元执行**，使用已有的网络和电脑。硬件沿用项目中已核对的 **79.90 元**标价，含运费和必需配件**总额最多 100 元**，以结账页为准。 [现有购物与安装指南](../00-随身版制作指南.md#1-下单和总价)

## 1. 板子到手就能试的功能

这些项目有对应的 **官方固件或板级源码**。打勾前要在实物上观察结果。

| 编号 | 功能 | 操作和通过标准 |
|---|---|---|
| F01 | Wi-Fi、手机热点、网页配网 | 连上小智配网热点，设置 2.4 GHz 网络。小智回到正常界面，能上网。 |
| F02 | 激活、绑定和换智能体 | 在控制台用六位码添加设备。修改角色昵称后重新发起对话，听它能否说出新昵称。 |
| F03 | 语音唤醒、按键唤醒 | 待机时说「你好小智」，设备进入聆听。另试双击 `BOOT/-`。断网时可观察是否有本地唤醒反应，联网语音回答另测。 |
| F04 | 多轮对话与语音识别、合成 | 先问「直角边长 3 和 4，斜边多长」，再问「为什么」。听它是否能接续上一问。 |
| F05 | 打断播报 | 请它说一段长回答。说唤醒词观察能否打断，另试双击 `BOOT/-`。分别记结果。 |
| F06 | 彩屏、表情与状态 | 观察待机、聆听和说话提示。请它开心地打招呼，观察表情变化。不同界面状态下字幕长度和出现时机可能不同。 |
| F07 | 时间、电量与网络状态 | 联网后等到空闲，屏幕时间和手机差不超过 1 分钟。观察电量图标和掉线提示，记录异常。 |
| F08 | 调音量、静音 | 先用 `+` 和 `BOOT/-` 比较音量，长按 `BOOT/-` 试静音，再用 `+` 恢复。另说「把喇叭音量调到 40%」，听下一句音量。 |
| F09 | 调亮度、切换浅色和深色 | 说「把屏幕亮度调到 35%」「把屏幕切换到深色主题」。看背光和配色是否实际变化。 |
| F10 | RGB 灯环调色、单灯和亮度 | 先说「灯环亮度等级设为 2，再把灯环调蓝色」。再试「把编号 0 的灯变成绿色」。灯号范围 0–7，亮度等级 0–8。 |
| F11 | 灯环闪烁和跑马灯 | 试「用蓝色闪烁，间隔 500 毫秒」「用绿色跑马灯，间隔 500 毫秒，长度 3」。观察当下变化，后续对话状态可接管灯效。 |
| F12 | 状态查询、重新配网与恢复 | 说「读取设备状态，告诉我喇叭音量和屏幕亮度」。需要换网时再说「让设备进入重新配网」，先确认再执行。配好后重测对话。 |
| F13 | 电池、待机调暗与热点重连 | 拔 USB 开机，先静置 10 分钟再唤醒。照续航表分开测待命、混合使用、连续聊天和歌曲播放。5–10 小时以实测为准。 |
| F14 | 固件更新、串口、备份与恢复 | 确认型号和当前版本。有官方更新时再验证 OTA；先留原机备份，串口参数与手动刷回见固件说明。 |

## 2. 官方账号的免费功能

打开控制台，选**绑定这台小智的智能体**，进入「配置角色」。复制 [初三学习角色](初三学习角色.txt) 到角色介绍，先用账号现有的免费模型和预设音色，保存并重新唤醒。公开权益表给普通开源用户列了小智 Lite、DeepSeek 量化版、预设普通话和其他语言音色，以及天气、笑话、音乐、新闻。项目 README 也说明个人用户可免费用 Qwen 实时语音。能否选择某个模型或服务，以你登录后的可用范围为准。 [小智控制台](https://xiaozhi.me/console/agents) · [官方权益表，开发者账号认证章节](https://xiaozhi.me/home/zh/docs/) · [小智官方 GitHub](https://github.com/78/xiaozhi-esp32#firmware-flashing)

| 编号 | 功能 | 操作和通过标准 |
|---|---|---|
| F15 | 角色、昵称和学习模式 | 复制角色介绍，改昵称。问它「你叫什么」，然后试初三数学提示和一轮英语口语。 |
| F16 | 对话语言和音色 | 在配置角色里改对话语言或试听并保存音色。用同一句话比较改动前后。固件菜单语言是另一个设置，见 F25。 |
| F17 | 切换免费语言模型和实时语音模型 | 用账号已有的免费选项比较同一个问题。模型切换后重测音乐、记忆和工具，遇到缺项可选回原模型。 |
| F18 | 播放免费歌曲 | 用官方音乐能力说「播放一首你能播放的儿歌」。听到曲调和唱词才算通过，免费曲目以实际返回为准。 |
| F19 | 短期记忆、免费额度内的长期记忆 | 先做 F04。若你的账号可免费启用长期记忆，先问测试代号做对照，再请它记住一个虚构代号。结束对话，重启开始新会话，隔天再问。官方维护者确认长期记忆已上线，公开权益文档曾标为限时免费。当前账号没有免费入口时，可以用 F28 的本机笔记记录指定内容。 |
| F20 | 账号开放的声纹辨认 | 声纹功能仅在账号可免费用时测试。到智能体的声纹识别，选自己或经同意者的一段清楚的历史语音，添加测试昵称。重新对话后问它正在和谁说话，做多次交叉测试。 |
| F21 | 天气、笑话、新闻 | 在账号的扩展能力里找并启用可见的项目。分别说「查北京现在的天气」「用笑话服务讲一个笑话」「查今天的新闻，说出日期和来源」。如后台有调用记录，核对确实调用了服务。 |
| F22 | 免费额度内的官方云知识库 | 账号有免费入口时，按下方步骤上传样例。官方公开公测指引列出普通开源用户可试 1 个库、1 个文档，实际额度看账号。等解析并绑定后，在电脑 MCP 程序关闭时问「查官方知识库，我的云知识库验收代号是什么」。账号暂未开放时，可用 F28 的本机知识卡。 |

**云知识库具体怎么做**

1. 在控制台找「知识库」，新建一个库，名称填 `小智随身版项目资料`。描述填「当我问小智随身版项目、云知识库验收代号、待办示例或口语练习示例时，检索这个资料库」。
2. 在知识库列表点击查看或进入详情，选择「新建文档」并上传 [云知识库样例](云知识库样例.txt)。待文档显示解析完成后，在这个智能体的角色配置里选择该知识库或启用对应能力，再保存。若账号没有入口、限制上传类型或显示需付费，按当前页面标明原因并跳过。
3. 回到小智发起新对话，照 F22 测试。先不给它答案。官方云知识库、本机知识卡和长期记忆使用不同的测试值。

依据是 [官方开发文档的服务端章节](https://xiaozhi.me/home/zh/docs/) · [音乐、模型、音色和声纹 FAQ](https://xiaozhi.me/xz-docs/docs/help-doc/xiaozhi-ai-chatbot-q%26a/) · [长期记忆上线说明](https://github.com/78/xiaozhi-esp32/issues/2107#issuecomment-4921403901)。
