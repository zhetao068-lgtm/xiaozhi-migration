# 把电脑上的学习工具接到小智

这 12 项工具在现有电脑上可免费运行。语音调用需要小智账号开放免费的 MCP 接入点，以及联网运行的电脑。两台设备可以用不同的网络。笔记、待办和计时数据存电脑。天气查询把城市名和地点坐标交给 Open-Meteo 的个人非商业免费接口。聊天、歌曲和官方记忆使用账号已有的官方服务。 [小智官方接入教程](https://xiaozhi.me/home/zh/docs/) · [官方示例](https://github.com/78/mcp-calculator) · [Open-Meteo 免费使用范围](https://open-meteo.com/en/pricing)

## 在 Windows 启动

1. 进入本文件所在的 `MCP` 文件夹，在资源管理器的地址栏输入 `powershell` 后回车。电脑上有 Python 3.11 可直接使用。没有时从 [Python 官方下载](https://www.python.org/downloads/windows/)，安装时启用 PATH。
2. 第一次运行以下命令。执行最后一行会自测，能看到「全部通过」。把最后一行加上 `--online` 会再真实查询一次北京天气。

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r .\requirements.txt
   .\.venv\Scripts\python.exe -B .\本机自测.py
   ```

3. 登录 [小智控制台](https://xiaozhi.me/console/agents)，打开当前设备的智能体 → 配置角色，在页面下方或「扩展能力／MCP 设置」内找「MCP 接入点」并复制。用下面的命令启动。出现提示时把地址粘贴在这台电脑的终端里并回车，输入时没有回显。地址含有访问凭据，留在自己电脑上。

   ```powershell
   .\.venv\Scripts\python.exe -B .\连接小智.py
   ```

4. 看控制台是否显示 MCP 已连接，再回设备开始**新一轮对话**并念下面的口令。若连接提示 400、401、403、404，检查自己选中的智能体和复制的完整地址。电脑休眠、关机或关闭终端时，这组扩展暂时无法被小智调用。再次开启只要运行第 3 步的命令。

## 用语音验收

| 对小智说 | 可观察到的结果 |
|---|---|
| 用学习工具算一下 12 乘 18。 | 216。 |
| 用学习工具查现在的北京时间。 | 返回电脑时钟的当前日期和时间。 |
| 用学习工具联网查北京的气温、体感和风速。 | 有明确地点、时间和 Open-Meteo 来源。 |
| 查电脑上的学习知识卡，验收代号是什么？ | 青柠四十二号。这是本机样例的专用测试值。 |
| 用学习工具存一条笔记，标题「练习」，内容「先画辅助线」。 | 新对话查询「练习」能读到这条。关掉电脑程序再开启后再试。 |
| 用学习工具删除标题「练习」的笔记。 | 再查同名笔记时，工具返回没有找到。 |
| 用学习工具添加待办「练习勾股定理」。 | 有编号。请它列出未完成待办，再按该编号完成，列表中消失。 |
| 用学习工具设一分钟学习倒计时。 | 立刻问还剩多久，等超过一分钟再问，分别显示剩余时间和已结束。到点不会主动播报。 |

笔记、待办、倒计时写入当前目录的 `学习数据.sqlite3`，退出程序后还在。正常运行时只保存主动要求写入的数据。程序不读取你的任意电脑文件。测试使用临时数据库。若只需基础小智或官方云功能，可直接关掉这个程序。

这份包在 Windows 本机用 WebSocket → MCP 子进程完整模拟了连接与工具调用，覆盖 12 项工具、两个会话和 25 次调用（含一次外网天气查询）。接到你的小智官方账号后仍需完成第 4 步。 [MCP Python SDK](https://github.com/modelcontextprotocol/python-sdk)
