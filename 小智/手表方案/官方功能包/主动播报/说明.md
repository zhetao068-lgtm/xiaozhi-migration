# 官方 notify 协议的主动播报样例

这个样例适合已经有**自己部署的兼容小智服务端**的人。官方 v2.5.2 固件在联网且空闲时，能接收服务端下发的 `notify` 并播放 Ogg Opus，附带的字幕按毫秒显示。忙于对话时设备会忽略该通知，离线不补发。公开文档尚未给出官网个人账号直接发送自定义通知的入口。 [官方 notify 协议](https://github.com/78/xiaozhi-esp32/blob/v2.5.2/docs/notify.md)

1. 把 [study-chime.ogg](study-chime.ogg) 放到设备能访问的 HTTPS 文件地址。URL 应直接返回 2xx 和文件内容。固件不会跟随跳转。
2. 打开 [notify示例.json](notify示例.json)，把示例域名改成自己的文件 URL。
3. 通过**自己的兼容服务端**，把这条 JSON 送入该设备当前协议的控制连接。使用官方文档的 `xz-mqtt` 路线时，可按其 Redis RPC `forward` 示例把这条 JSON 放进 `params`，用自己设备对应的 client ID。
4. 把自己的小智放在已联网的空闲界面测试。听到提示声并看见字幕才算完成。单独记录对话中和断网时的行为。

铃声为随包源码合成的三个音，约 1.5 秒。FFmpeg 已实际解码检查，编码为单声道 Opus、48 kHz、20 毫秒帧。[生成提示音.py](生成提示音.py) 用已安装且支持 `libopus` 的 FFmpeg 可重新生成。还没有向实物或官方服务器发送通知。
