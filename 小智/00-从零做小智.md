# 免焊小智机器人｜从拆包到第一次对话

做约 60 元、带屏幕和电池的随身版，请打开 [最终方案](最终方案.md)。本页是最初的 Xmini-C3 USB 桌面版教程，可查阅配网和故障排查步骤。

**推荐买 Xmini-C3 普通 Wi-Fi 版，加一个带插头的喇叭。** 主板自带麦克风和功放，插上喇叭、连上 USB，就可以开始烧录。用家里现成的数据线，按 58 元主板、4 元喇叭、8 元运费算，正好 70 元。这是算账示例，实际要看结账页。购买时先看 [购物清单和比价](01-购物清单和比价.md)。

做完后，按一下板上的 **BOOT** 键，说一句话，喇叭就会回答。这个版本是桌面语音助手，使用时接着 USB，并通过家里的 Wi-Fi 连接小智的在线服务。预算版先做语音对话，屏幕看商家是否随板附送。用 BOOT 键演示，成功标准不依赖语音唤醒。

## 1. 到货后先接喇叭

1. 拿出主板，按卖家的实物图找到 **Type-C 口、电源拨动开关、BOOT 键、喇叭插座**。有两个外形相近的两针插座时，先分清喇叭口和电池口。可以对照 [斑梨 Xmini-C3 商品页的接口图](https://spotpear.cn/index.php/shop/ESP32-Xmini-C3-AI-DeepSeek-XiaoZhi-XiaGe-Qwen-DouBao.html)。
2. 保持 USB 拔掉、电源开关关闭，把喇叭的两针插头对准 **喇叭口**，轻轻插到底。插头对不上就停下来核对规格。主板放在干燥、平整的非金属桌面上。如果买的是已经组装好的备选套件，直接使用其内置喇叭。
3. 准备一台 Windows 10/11 电脑、一条能传文件的 USB 数据线，以及一部能连家里 Wi-Fi 的手机。可以先用同一条线连手机和电脑，看能否选择“文件传输”，顺便确认线能传数据。用 USB 给小智供电即可。

```text
电脑 USB ── 数据线 ── Xmini-C3 的 Type-C 口
                        └── 喇叭口 ── 带插头的喇叭
```

如果卖家已预装小智固件，正常开机后能听到配网提示，或者手机能看到 `Xiaozhi-…` 热点，可以直接做第 3 步。想体验烧录，或板子没有小智程序，就做第 2 步。已经可以对话的设备如需重刷，先保存卖家给的原厂固件，方便恢复原来的配置。

## 2. 用 Windows 烧录

烧录就是把程序写进主板。这个文件夹已经放好了 [直接烧录的 merged-binary.bin](固件与源码/merged-binary.bin)。建议把它复制到一个短的英文路径，例如 `C:\xiaozhi\merged-binary.bin`。源码 ZIP 留给以后看代码和编译。

1. 下载 Windows 版 **Flash 下载工具**，把下载的 ZIP 全部解压，再双击里面的 `flash_download_tool` 程序。 [直接下载乐鑫工具 ZIP](https://dl.espressif.com/public/flash_download_tool.zip)
2. 让小智进入下载模式。先关掉主板的电源开关，用数据线连电脑。按住板上的 **BOOT**，打开电源开关，等电脑发现设备后再松手。打开 Windows「设备管理器 → 端口（COM 和 LPT）」记下新增的 `COM` 号。若有多个串口，插拔对照，选随这块板出现的那一个。 [小智官方 Xmini-C3 烧录图解](https://xiaozhi.me/xz-docs/docs/dev-boards/xmini-c3-dev-board-for-xiaozhi-ai/)
3. 工具弹窗里，`ChipType` 选 **ESP32-C3**，`WorkMode` 选 **Develop**。如果有 `LoadMode`，按 Xmini-C3 图解选择 **UART**，然后点 **OK**。
4. 第一行点 `…`，选 `merged-binary.bin`，在右边的地址框填 **`0x0`**，勾上这一行。`DoNotChgBin` 如果可勾选就保持勾选，其余 SPI 参数保留默认。底部 `COM` 选你的端口，`BAUD` 先用 **115200**。 [乐鑫烧录工具界面说明](https://docs.espressif.com/projects/esp-test-tools/zh_CN/latest/esp32c3/production_stage/tools/flash_download_tool.html)
5. 点 **START**，等显示 **FINISH / 完成**。这段时间保持 USB 连接。首次烧录按上述步骤直接写入，保留 `ERASE` 按钮供确实需要清除旧配置时使用。烧完关闭工具，电源拨到关再拨到开，重启时松开 BOOT 键。

**按下 START 前看一眼型号。** 本文件只给原版 **Xmini-C3 普通 Wi-Fi 版**。固件启动时会写入一项不可恢复的芯片配置，刷到不匹配的板有可能损坏它。板子只写了“ESP32-C3”，或者明确标了 **V3、4G、S3**，都先停下来按实物型号另找固件。 [对应板型的官方源码](https://github.com/78/xiaozhi-esp32/blob/v2.5.2/main/boards/xmini/c3/xmini_c3_board.cc)

## 3. 用手机配网并绑定

1. **让小智上网。** 正常开机后，在手机的 Wi-Fi 列表点 `Xiaozhi-…` 热点。如果手机说这个网络无法上网，选继续连接。稍等配网页弹出。如果没弹出，保持连接该热点，在浏览器地址栏输入 `http://192.168.4.1`。
2. 在配网页选择家里的 **2.4 GHz Wi-Fi**，输入密码并连接。用家里普通路由器最容易，校园网等需要网页二次登录的网络先跳过。小智连上后会自动重启或退出配网，手机这时切回正常上网。 [小智官方配网图解](https://xiaozhi.me/xz-docs/docs/dev-boards/xmini-c3-dev-board-for-xiaozhi-ai/)
3. **把小智加到账号。** 等设备联网，听它报出六位设备码，有屏幕时也可以看屏幕。没有提示就短按一次 **BOOT** 触发对话。和家长一起登录小智官网，进入「控制台 → 智能体」，新建一个智能体，再点「添加设备」，填刚才的六位码。如果页面让你选接入类型，DIY 设备选「开源版」，按控制台当前规则完成绑定。先用平台提供的基础功能，不购买会员或额外模型服务。如果页面要求付费，先停下核对。 [小智官网](https://xiaozhi.me/)

## 4. 做三次验收

- [ ] **能听也能说。** 在安静的地方短按 BOOT，说“请用一句话解释为什么会打雷”，等喇叭回答。
- [ ] **能分辨新问题。** 等它说完再按一下，说“用英语向我打个招呼”。能听到针对新问题的回答，就验证了麦克风、网络和喇叭。
- [ ] **重启后还能用。** 电源关一次再开，等它连回 Wi-Fi，再按 BOOT 问一句。控制台能看到这台设备，重启后也能继续对话，就做完了。

## 卡在哪一步，就先查这一行

| 看到的情况 | 先这样处理 |
|---|---|
| 电脑没出现 COM 口 | 换一条能传文件的数据线，直插电脑的 USB 口。关机，按住 BOOT 再开机，重新看设备管理器。 |
| START 后提示连接失败 | 关掉占用同一个 COM 口的串口工具，重新进下载模式，确认端口和 `ESP32-C3`，用 115200 再试一次。 |
| 烧完看不到热点 | 电源关一次再开，开机时松开 BOOT。旧板可能已记住 Wi-Fi。换过路由器时，可在开机还没连上网时短按 BOOT，或按官方图解重新配网。 |
| 看到了热点，手机进不去配网页 | 让手机保持连接小智热点。关掉手机的自动切网或临时关闭移动数据，手动打开 `http://192.168.4.1`。 |
| 找不到家里的 Wi-Fi | 确认路由器开了 2.4 GHz。也可以用另一部手机开 2.4 GHz 热点，让配网手机继续连小智热点。 |
| 已配网，听不到声音 | 拔 USB 并关机，确认喇叭插在正确的口并插紧，再开机。看得到提示却始终没声音，先核对喇叭规格和音量。 |
| 设备码绑定失败 | 区分短信登录码与设备六位码。用设备最新播报的码重试。若提示已被绑定，找卖家处理原账号解绑。 |
| 听到开机声，聊天却没有回答 | 先确认该 Wi-Fi 可以上网、设备已绑定，再检查小智控制台的服务状态。若同一问题持续出现，记录灯光、屏幕提示或报错原文再排查。 |

本地已核对固件校验值、芯片类型和源码版本。烧录、配网和对话需要拿到板后按本页验收。
