# Xmini-C3 普通 Wi-Fi 版一键烧录

已预装小智且能正常配网的设备，直接用出厂程序。下面适用于确实要重刷的 **Xmini-C3 原版普通 Wi-Fi 版，ESP32-C3、16 MB**。根据订单和板背确认卖家指明用 `xmini-c3`。官方源码在启动时会设置一项不可逆的芯片配置，错刷可能损坏硬件。若商家说用 `xmini-c3-v3`、`xmini-c3-4g`，或只说「ESP32-C3」，先按实物型号确认。电脑能识别 ESP32-C3 芯片这一点无法证明主板版型。 [原版硬件说明](https://oshwhub.com/tenclass01/xmini_c3) · [官方固件源码](https://github.com/78/xiaozhi-esp32/blob/v2.5.2/main/boards/xmini/c3/xmini_c3_board.cc)

1. Windows 电脑只接这一台小智。关机，用 USB 数据线连电脑，按住 **BOOT**，再将电源拨到开，电脑出现新端口后松开。 [官方烧录图解](https://xiaozhi.me/xz-docs/docs/dev-boards/xmini-c3-dev-board-for-xiaozhi-ai/)
2. 在资源管理器双击 [双击烧录.cmd](双击烧录.cmd)。核对后键入 `XMINI-C3`，按回车。程序会用乐鑫工具检查芯片、闪存和安全配置，完整备份再写入和读回校验。备份在 `%LOCALAPPDATA%\Xiaozhi-Xmini-C3\Backups`，其中可能保存原机 Wi-Fi 设置，请自己保管。 [乐鑫 esptool v5.6.0](https://github.com/espressif/esptool/releases/tag/v5.6.0)
3. 看见「烧录和读回校验通过」后拔 USB，把电源拨到关再拨到开，松开 BOOT，按 [根目录方案](../../最终方案.md) 配网。

启动器读取已有的 [官方整包 BIN](../../固件与源码/merged-binary.bin) 和 [乐鑫便携 esptool](../../手表方案/固件/C6-直接烧录/esptool.exe)，请保留整个小智文件夹的目录结构。源码及固件校验值见 [官方固件和源码说明](../../固件与源码/文件和编译说明.md)。BIN 和 GitHub 发布附件匹配，未加入厂商资源。电脑上检查了文件、目标芯片、Flash 头、分区表及无板时的退出行为。实际写入与首次启动待同型号实物测试。
