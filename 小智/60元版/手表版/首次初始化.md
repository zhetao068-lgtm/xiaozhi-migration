# 已烧录的小智怎么初始化

**第一次就做三件事**。开机、连 2.4 GHz Wi‑Fi、绑定账号。按当前屏幕或卖家提示操作。如果你的机器显示其他服务器或配网地址，先核对卖家说明，保留已经能启动的固件。

1. **开机看屏幕。** 裸板放在干燥的非金属桌面，插好已配对的电池、喇叭，拨到开机。看到「配网模式」或听到配网提示就继续。已能对话的设备可先在控制台确认绑定状态。
2. **连小智发出的热点。** 手机打开 Wi‑Fi，选屏幕显示的 `Xiaozhi-…`。手机提醒「无互联网」时选保持连接。如果配网页没有自动弹出，在浏览器地址栏输入 `http://192.168.4.1`，以设备屏幕给出的地址为准。 [上游固件首次启动说明](https://xiaozhi.dev/docs/usage/activation/)
3. **选能上网的 Wi‑Fi。** 配网页里选家里的 **2.4 GHz Wi‑Fi**，输入密码，点连接。想在外面用，可以让一部手机开 **2.4 GHz 热点**，用另一部手机或电脑连小智的临时热点去配。先用家里 Wi‑Fi 最方便。若配网后手机还连在小智热点，切回能上网的网络。 [网络配置说明](https://xiaozhi.dev/docs/usage/network-setup/)
4. **绑定设备。** 小智联网后会显示或播报验证码。若屏幕给的是小智官方服务，打开 [小智控制台](https://xiaozhi.me/console/)，用你或家长的账号登录，进入「智能体」新建或选一个角色，再选「添加设备」，填机器显示的 **6 位设备码**。手机收到的短信码用于登录。 [官方常见问题](https://xiaozhi.me/xz-docs/docs/help-doc/xiaozhi-ai-chatbot-q%26a/)
5. **试一句。** 屏幕出现待机或连接成功后，按一下卖家标明的对话键，再说「用一句话告诉我为什么会打雷」。看到屏幕变化且听到回答后，关机再开一次，确认能自动回连。取下 USB 再试一次，确认能靠电池工作。

| 遇到的情况 | 这样处理 |
| --- | --- |
| 手机找不到 `Xiaozhi-…` | 先重启，看屏幕是否已连上卖家测试的网络。如果仍没出现热点，按卖家说明使用配网键。按键时机随板型和固件变动。 |
| 手机能连设备热点但网页打不开 | 确认手机还连着小智热点，再在地址栏输入 `http://192.168.4.1`。 |
| 提示设备已绑定 | 找卖家从原账号解除绑定，再重新获取设备码。 |
| 绑定后要用记忆、点歌 | 到智能体的配置中找免费记忆入口，试一句「记住我喜欢蓝色」。点歌可先试儿歌，曲库与免费权限以控制台实际显示为准。 |
| 想让它显示时间 | 联网后看待机界面，有些固件会在状态栏显示时间或在省电时关屏。能否当表盘用取决于你这套已装固件。 |
